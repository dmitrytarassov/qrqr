# qrqr — генератор QR-кодов

Минималистичный web app для генерации QR-кодов. Один экран, ноль шагов,
мгновенный результат. Полная дизайн-спека: @docs/DESIGN.md — прочитай её
перед любой работой над UI.

## Продуктовые правила (не нарушать)

- НЕТ кнопки «Generate». QR перестраивается в реальном времени при вводе.
- Mobile-first. Десктоп — адаптация мобильной версии, не наоборот.
- Один акцентный цвет во всём интерфейсе: `#C8FF00` (лайм). Никаких
  вторых акцентов, градиентов в UI, теней-неонов. Единственное место,
  где живёт градиент, — модули самого QR-кода (5 пресетов).
- QR-код всегда тёмные модули на светлой карточке — в том числе в тёмной
  теме. Инверсные QR плохо сканируются.
- Настройки спрятаны: тап/клик по коду → bottom sheet (мобайл) или
  поповер (десктоп). Никаких настроек на главном экране.
- Кастомизация ограничена тремя вещами: цвет модулей (5 градиентных
  пресетов), форма модулей (квадрат/скруглённый/точки), логотип в
  центре. Больше ничего не добавлять.
- Тёмная тема только через `prefers-color-scheme`, без переключателя.

## Технические правила

- Размер шрифта поля ввода ≥16px — иначе iOS Safari зумит при фокусе.
- Лейаут на `100dvh`; нижние кнопки с `env(safe-area-inset-bottom)`.
- QR рендерить в `<img>` (canvas → dataURL), не inline SVG — нужен
  long-press → «Сохранить изображение» на iOS.
- Главное действие на мобиле — Web Share API с файлом
  (`navigator.share({ files })`), с fallback на скачивание.
- Кнопка «Вставить» — `navigator.clipboard.readText()`.
- Многострочный ввод: авторастущий textarea или contenteditable,
  не однострочный input.

## Тон

- Копирайт короткий и наглый: «вставил. скачал. всё.»
- Никаких «Free QR Code Generator», звёздочек, маркетинговых эпитетов.
