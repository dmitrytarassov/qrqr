# qrqr — дизайн-спека

## Концепция

Боль рынка: существующие генераторы — форма из 2010-го, обвешанная
рекламой, с «Download» за пейволом. qrqr — противоположность: один
экран, ноль шагов, мгновенный результат.

Главная идея: **QR-код — живой объект**. Он генерируется в реальном
времени, пока пользователь печатает. Кнопки «Generate» не существует.
Код рождается и перестраивается с каждым символом, с плавной анимацией
модулей (появление/исчезновение со stagger-эффектом, ~150 мс).

Формула: скорость как фича + один яркий цвет + одна живая анимация.
Всё остальное — тишина.

## Приоритет: мобильная версия

Главный сценарий — «скинуть ссылку с телефона». Десктоп — адаптация.

### Мобильный лейаут (вертикальный стек)

Сверху вниз:

1. Шапка: логотип `qrqr` слева, слоган «вставил. скачал. всё.» справа,
   мелко, почти незаметно.
2. Поле ввода: сверху, чтобы клавиатура его не перекрывала.
   Подпись-плейсхолдер: «ссылка, текст, что угодно». Рядом с полем —
   кнопка «Вставить» (`navigator.clipboard.readText()`), потому что на
   телефоне URL вставляют, а не печатают.
3. QR-код: по центру экрана, на белой карточке со скруглением 18px.
4. Нижний блок (зона большого пальца, `env(safe-area-inset-bottom)`):
   - Главная кнопка «Поделиться» — единственная тёмная кнопка на
     экране, полная ширина, с лаймовой иконкой share внутри.
     Вызывает Web Share API с PNG-файлом; fallback — скачивание.
   - Под ней вторичные текстовые ссылки: PNG · SVG · Copy.
   - Микроподпись: «тап по коду — настройки».

Лейаут на `100dvh`: при выезде клавиатуры экран честно сжимается,
кнопка «Поделиться» не прячется.

### Поле ввода

- Гигантский моноширинный текст, а не «инпут в рамочке».
  Мобайл ~19–22px (но не меньше 16px — iOS зумит), десктоп 30–40px.
- Многострочный: авторастущий textarea или contenteditable. URL на
  узком экране ломается на строки, горизонтальный скролл запрещён.
- Каретка — лаймовый блок (#C8FF00), единственное пятно цвета
  в состоянии покоя.
- Автофокус при открытии страницы.

### Bottom sheet настроек (тап по коду)

Шторка перекрывает низ экрана, QR остаётся виден сверху
(приглушённый, opacity ~0.35) — выбор цвета применяется вживую,
без кнопки «применить». Внутри ровно три секции:

1. **Цвет модулей** — 5 пресетов-кружков: #111110 (дефолт), #2B2BFF,
   #FF4D00, #0F6E56, #993556. Выбранный обведён лаймовым кольцом
   (outline 2px + offset 2px). Никакого color picker.
2. **Форма модулей** — квадрат / скруглённый / точки.
3. **Логотип в центре** — «выбрать из галереи» (на десктопе drag&drop
   прямо на код).

Больше настроек не добавлять. Градиенты, рамочки «SCAN ME» — к
конкурентам.

## Десктопный лейаут

Один экран по центру, без скролла. Двухколоночная сетка: слева
гигантский ввод + кнопки PNG/SVG/Copy (тихие, с тонкой рамкой),
справа QR ~320–400px на белой карточке. Настройки — поповер у кода,
не модалка. Микроподпись: «обновляется, пока печатаешь · клик по
коду — настройки».

## Цвет

- Фон светлой темы: тёплый почти-белый `#FAFAF7`.
- Фон тёмной темы: `#111110`. Переключение только через
  `prefers-color-scheme`, без тумблера.
- Чернила: `#111110` / в тёмной теме `#FAFAF7`.
- Акцент: электрический лайм `#C8FF00`. Ровно один. Живёт в каретке,
  hover-состояниях, кольце выбора, иконке share. На светлом фоне
  лайму нужен тонкий тёмный outline (#9BC400) для читаемости.
- Серые: #8A887F (вторичный текст), #B4B2A9 (подписи),
  #D3D1C7 (рамки), #E8E6DF (разделители).
- **QR-код всегда тёмный на светлой карточке**, включая тёмную тему.
  Инверсные QR многие камеры не читают. В тёмной теме это можно
  честно объяснить микроподписью.

## Типографика

- UI: гротеск с характером — Space Grotesk или Instrument Sans.
- Введённый текст/URL: моноширинный — JetBrains Mono или Geist Mono.
- Слоган и подписи — мелкие (11–13px), приглушённые.

## Микродетали

- Stagger-анимация модулей при перестройке кода (~150 мс).
- Subtle 3D tilt QR-карточки за курсором, 2–3° (только десктоп).
- Hover по QR — модули на мгновение перекрашиваются в акцент
  (сканируемость не страдает, это hover).
- Пустое состояние: декоративный паттерн из модулей, который
  «собирается» в код при вводе. Страница никогда не пустая.
- Copy кладёт PNG в буфер (Clipboard API) + микроконфетти из
  квадратиков-модулей в акцентном цвете.
- Long-press по QR на мобиле → нативное «Сохранить изображение».
  Для этого QR рендерится как `<img>` (canvas → dataURL), не inline
  SVG: iOS не даёт long-press-меню на SVG.

## Тон

Название: qrqr (варианты: blip, скан.точка). Один слоган:
«вставил. скачал. всё.» Никаких «Free QR Code Generator ★★★★★»,
никакой рекламы, никакого пейвола на скачивание.
